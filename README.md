# 🛒 E-commerce Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to uncover meaningful insights into customer behavior, product performance, and revenue trends. The goal is to transform raw data into actionable business insights using industry-standard data analytics tools.

---

## 🎯 Objectives

* Analyze sales performance across time
* Identify top-selling products and categories
* Understand customer purchasing behavior
* Build key performance indicators (KPIs)
* Create an interactive dashboard for business decision-making

---

## 🛠️ Tools & Technologies

* **Excel** → Data Cleaning & Preprocessing
* **MySQL** → Data Analysis & Querying
* **Power BI** → Data Visualization & Dashboard

---

## 📊 Key Analysis Performed

### 🔹 Data Cleaning (Excel)

* Removed duplicates and handled missing values
* Standardized date and numeric formats
* Created calculated column: **Revenue = Quantity × Price**

---

### 🔹 SQL Analysis (MySQL)

* Total Revenue Calculation
* Monthly Sales Trend Analysis
* Top 5 Selling Products
* Top Customers by Revenue
* Category-wise Performance

---

### 🔹 Dashboard (Power BI)

An interactive dashboard was created to visualize:

* 💰 Total Revenue
* 🛒 Total Orders
* 👤 Total Customers
* 📈 Monthly Sales Trends
* 📊 Top Selling Products
* 🥧 Category Distribution
* 🌍 Sales by City

---

## 📈 Key Insights

* Identified high-performing products contributing to maximum sales
* Observed seasonal trends in revenue growth
* Found that a small group of customers drives a significant portion of revenue
* Certain categories consistently outperform others
